== Highlighted source blocks

With `source-highlighter` set to `highlight.js`, code blocks carry client-side highlighting language classes.

[source,yaml,options="nowrap",subs=attributes+]
----
apiVersion: v1
kind: ConfigMap
metadata:
  name: sample-config-map
data:
  key: "value"
----

[source,bash,options="nowrap"]
----
oc apply -f config-map.yaml
----
